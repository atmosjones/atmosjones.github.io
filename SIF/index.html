Resolving Crop-Specific Solar-Induced Fluorescence using Overlapping OCO-2 Target-Mode Soundings

Taylor S. Jones, Jonathan F. Dooley, Russell Goebel, Leeza Moldavchuk, Aamer Ali, Jia Chen

Submitted to Geophysical Research Letters

Analysis code

The R scripts used in the paper. The README explains how to run them and which script makes each figure.

  • Browse the scripts on GitHub
  • run_all.sh: runs the main analysis in order
  • downscale_sif_inversion.R: the grid inversion
  • downscale_sif_by_crop_cdl30.R: the crop-class inversion
